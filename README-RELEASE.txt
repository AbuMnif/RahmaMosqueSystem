منظومة عَون الإدارية — تحديث السجل التعليمي 1.1.6

التعديلات:
1) إصلاح عرض حقول التاريخ على الجوال: تصبح الحقول بعرض كامل وعمود منفصل لتجنب تداخل عناصر التاريخ في iOS.
2) إضافة قائمة بأسماء سور القرآن الـ114 في نموذج الحفظ والمراجعة. تُعرض أسماء السور للمستخدم، مع استمرار إرسال/تخزين رقم السورة في قاعدة البيانات للحفاظ على توافق المخطط الحالي.
3) منع النقر المتكرر على حفظ السجل: قفل أثناء الإرسال، تعطيل زر الحفظ وإظهار حالة «جارٍ الحفظ»، وإغلاق النموذج بعد تأكيد نجاح الخادم أو نجاح التخزين المحلي.
4) إضافة مهلة لطلبات تحميل وحفظ السجلات. عند تعذر الاتصال أو انتهاء المهلة، تحفظ العملية محليًا بمعرّف idempotency واحد لإعادة المزامنة دون إنشاء تكرارات.
5) عدم عرض مؤشرات صفرية وكأنها بيانات حقيقية إذا فشل التحميل عبر الإنترنت ولم توجد نسخة محلية؛ تظهر رسالة خطأ وزر إعادة المحاولة.
6) عرض اسم السورة في جدول السجلات وملخص آخر السجلات بدل رقم السورة.

مهم:
- لم يتغير مخطط قاعدة البيانات؛ حقل surah_number يبقى رقمًا كما يتطلب كود API الحالي.
- لم يتم تنفيذ بناء Next.js كامل في هذه البيئة؛ npm install لم يكتمل ضمن مهلة التنفيذ. تم التحقق من سلامة أرشيف ZIP وفحص JavaScript الأساسي، لكن يلزم تأكيد البناء والنشر من GitHub Actions/Vercel.
- هذا الإصدار مبني على Awn-v1.1.5.zip.
